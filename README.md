# NogneVideos 🎮

## 📌 Sobre o Projeto
O **NogneVideos** é uma página web criada para reunir, organizar e exibir uma curadoria especial de vídeos do YouTube focados nas histórias, mistérios e *lores* do mundo dos games. É o espaço perfeito para quem gosta de mergulhar a fundo nas narrativas dos seus universos favoritos!

Este projeto foi desenvolvido com o objetivo de praticar a estruturação de conteúdo web, o desenvolvimento de layouts organizados e a incorporação de mídias externas.

## 🚀 Acesse o Site
🔗 **[Clique aqui para acessar o NogneVideos](https://marinogne.github.io/nognevideos/)**

## 💻 Tecnologias Utilizadas
* **HTML5:** Responsável pela marcação, estrutura da página e utilização da tag `<iframe>` para incorporar os vídeos diretamente do YouTube.
* **CSS3:** Responsável pela estilização visual, paleta de cores e organização do layout (distribuição dos vídeos na tela).

## 🧠 O que foi praticado
Durante a construção deste site, pude colocar em prática:
* Estruturação semântica do HTML.
* Organização de elementos visuais e alinhamento usando CSS.
* Incorporação de conteúdos de terceiros (YouTube Embed) de forma limpa e responsiva.
